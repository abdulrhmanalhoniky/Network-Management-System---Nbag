# NMS (Network Management System) - Nbag(Networkbag)

A desktop Network Management System (Desktop NMS) built in Python with a modern graphical interface using CustomTkinter, designed to automate network tasks and perform scans easily and professionally.

## 🚀 Tools and Features
-Ping Tool: Check the responsiveness of devices and domains with built-in DNS Resolution support.

-Port Scanner: Scan open ports for various services on different target devices.

-Netmiko Automation: Automate network device configurations and commands (such as Cisco) via the SSH protocol.

-Packet Analyzer: A lightweight packet analyzer and monitor for data flow and Round Trip Time (RTT).

-Custom Logging System: A flexible, color-coded logging system within the interface to easily distinguish between successes and errors.

## 🛠️ Tech Stack 
-Python 3.11

-CustomTkinter (for a modern GUI)

-Netmiko (for network device automation)

-Socket / Subprocess (for networking tools and connectivity)
